# Формула Квест

8-сынып информатикасы: **«Статистикалық мәліметтер. Абсолютті және салыстырмалы сілтемелер»**. Ойын түріндегі интерактивті сабақ: браузердің ішінде нағыз жұмыс істейтін мини-Excel, 6 деңгей, финалдық босс, XP/ранг/жетістіктер, сертификат.

Оқушы бөлігі — таза HTML/CSS/JS (сыртқы кітапханасыз, шрифттері жергілікті). Серверлік бөлік тек нәтижелерді жинау үшін.

## Мұғалімге: 6–10 балл және жасырын панель
- Оқушы кіргенде **аты-жөнін және сыныбын** жазады. Әр деңгейден кейін нәтиже сайтқа үнсіз жіберіледі, оқушыға балл көрінбейді.
- Мұғалім панелі — **жасырын**: бетте түймесі жоқ. Ашу жолдары: мекенжайға `#/teacher` қосу немесе логотипті **3 рет жылдам басу**. Кіру — құпиясөзбен.
- Панельде: сынып сүзгісі, іздеу, әр оқушының деңгейлері мен көмек саны, **балл (6–10)**, баллдардың таралуы, CSV жүктеу, басып шығару, оқушының нәтижесін өшіру.
- Баллды жиналған XP үлесі анықтайды (қосымша тапсырмасыз мінсіз өту ≈ 96%): **≥85% → 10, ≥70% → 9, ≥55% → 8, ≥40% → 7, одан төмен → 6**. Шектерді панельдегі «Бағалау шкаласы» бөлімінен өзгертуге болады. Ештеңе істемеген оқушыға балл қойылмайды (—).
- Кіргеннен кейін деңгейлерде «▶ Демо» және «✔ Шешімді көрсету» құралдары қосылады (тек мұғалім сессиясында) және 📋 сабақ жоспары ашылады.

> Нәтиже оқушының браузерінен келеді, сондықтан мұқият оқушы оны өзгерте алады. Бұл сабақтағы қолдануға жеткілікті, бірақ ресми емтихан үшін емес.

## Vercel-де іске қосу
1. Репозиторийді Vercel-ге жоба ретінде қосыңыз (`vercel.json` бәрін өзі баптайды).
2. **Storage → Create → Blob** (Public немесе Private — екеуі де жарайды), жобаға **Connect** жасаңыз.
3. **Settings → Environment Variables**: `TEACHER_PASSWORD` — мұғалім құпиясөзі, **кемінде 6 таңба**. Қосымша: `SESSION_SECRET` — кездейсоқ жол.
4. **Redeploy**. Құпиясөзсіз панель өшірулі болады, ал Blob-сыз нәтижелер сақталмайды (панельде хабарлама шығады).

## Жергілікті іске қосу
```
npm install
TEACHER_PASSWORD=құпиясөз npm start      # http://localhost:8080, мұғалім: /#/teacher
npm test
```
Жергілікті режимде нәтижелер `data/` ішінде сақталады (git-ке түспейді).

## Құрылым
- `public/`: оқушы сайты (`js/engine` — формулалар мен сілтемелер, `js/ui` — кесте, `js/game` — деңгейлер, балл, мұғалім панелі).
- `api/`, `lib/`: нәтижелерді жинау (`POST /api/submit`) және мұғалімге арналған `GET/DELETE /api/results`, `/api/teacher` (cookie-сессия).
- `test/`: қозғалтқыш, деңгей шешімдері, бағалау шкаласы, API.
