# Формула Квест

8-сынып информатикасы: **«Статистикалық мәліметтер. Абсолютті және салыстырмалы сілтемелер»**. Ойын түріндегі интерактивті сабақ: браузердің ішінде нағыз жұмыс істейтін мини-Excel, 6 деңгей, финалдық босс, XP/ранг/жетістіктер, сертификат.

Таза HTML/CSS/JS, сыртқы кітапханасыз, шрифттері жергілікті. Құрастыру қадамы жоқ.

## Іске қосу
```
npm start        # http://localhost:8080
npm test         # қозғалтқыш пен деңгей шешімдерінің тесттері
```
Vercel-де: репозиторийді қосу жеткілікті (`vercel.json` түбірді статика ретінде береді).

## Мұғалімге
- Жоғарғы жолдағы 👩‍🏫: барлық деңгей ашылады, «▶ Демо» формулаларды өздігінен жазып көрсетеді, «✔ Шешімді көрсету», талқылау сұрақтары, 📋 45 минуттық жоспар.
- Тікелей сілтемелер: `#/map`, `#/level/addr|stats|relative|absolute|share|mixed`, `#/boss`, `#/sandbox`.

## Құрылым
- `js/engine/`: формулалар, сілтемелер (`A1`, `$A$1`, `$A1`, `A$1`), диапазондар, көшіру/толтыру, F4.
- `js/ui/`: кесте компоненті, X-ray панелі, маскот, эффектілер.
- `js/game/`: деңгейлер (`levels.js`), викторина, прогресс, бағыттау.
